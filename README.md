# 快捷班列冷链衔接

本项目服务于协调快捷班列时刻、冷链货物与两端接驳。仓库保存领域资料、交换契约和可运行的服务入口，便于参与方在同一语义下协作。

## 领域事实

- 客车化快捷班列服务电商和冷链市场
- 班列按稳定时刻组织运输
- 铁路同时提供门到门联运服务

## 核心规则

- 装载决定（上本班 / 转下一班 / 就地处置）由班次时刻、装卸截止、货品耐受窗口、传感器质量、车厢能力与目的站接驳共同判定，逐条给出理由，不靠电话拍板
- 托盘拆分、合并、转班都保留原始批次号（lineage）
- 温度补报不得覆盖已触发的隔离，只有附业务依据的人工放行可以解除
- 优先级变化必须给出业务依据
- 站场多人同时占用容量时原子检查，不可超装；断网重试按占用键幂等
- 断网扫描恢复后按现场时间（occurred_at）校正事件顺序
- 发货人、铁路、接驳商各自只看到必要数据

## 目录说明

- `contracts/` 保存交换数据的结构约定。
- `fixtures/` 提供去标识的领域样例。
- `src/models.py` 领域模型：班次、车厢、批次、耐受参数。
- `src/decision.py` 装载决策与判定理由。
- `src/yard.py` 站场编排：温控隔离、拆并转班、临时换编、装载执行。
- `src/capacity.py` 容量原子占用，并发不超装。
- `src/events.py` 附录式事件日志，双时间戳，人工操作强制业务依据。
- `src/manifest.py` 截关可执行清单，按优先级分配容量。
- `src/dispute.py` 货损争议说明：等待、温控、人工放行如何影响结果。
- `src/views.py` 发货人 / 铁路 / 接驳商三种数据视图。
- `src/scenario.py` 复合异常演示：公路晚到 + 温控异常 + 临时换编。
- `tests/` 核对领域资料与全部业务规则。

## 本地检查

运行 `python3 -m unittest discover -s tests -v` 可以检查当前资料与服务入口。

## 服务入口

`python3 -m src.server` 后：

- `GET /health` 健康检查
- `GET /context` 领域上下文
- `GET /manifest` 复合异常场景下的截关清单
- `GET /dispute/<批次号>` 批次货损时间线与影响因素
- `GET /view/<批次号>?role=shipper|railway|connector&requester=<发货人>` 角色视图

也可直接运行 `python3 -m src.scenario` 查看清单与争议说明的完整输出。
